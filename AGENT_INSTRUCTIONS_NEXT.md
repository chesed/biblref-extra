## 1. Executive Summary & Goals

`bibleref-extra` currently extends the LaTeX `bibleref` stack (`bibleref`, `bibleref-parse`, `bibleref-sbl`) with:
1. Modular non-canonical book registration (Second Temple, Church Fathers, Qumran).
2. Automatic on-the-fly registration of anonymous Qumran shelf marks (`4Q413`, `11Q5`, etc.).
3. The `\bref` router which dispatches mixed lists in reading order, groups standard runs, passes Qumran marks to `\qref`, and handles `cf.` prefixes.

### The New Deliverables:
1. **Interactive Hyperlinks (Plain-Text Aesthetic):**
   - Every Bible/Qumran reference generated by `\bref` or `\qref` must become an active clickable PDF hyperlink (`\href`).
   - **Crucial Appearance Rule:** The links must look like **plain text** (matching the surrounding font, color, with no blue coloring, no underlines, and no bounding boxes), conforming to standard academic typesetting.
2. **Multi-Provider Web App Routing:**
   - **Logos Bible Web App (Default):** Deep links via Logos `ref.ly` service (`https://ref.ly/...`), directing users directly into the passage in the Logos Web App or Desktop application.
   - **Biblia.com:** Pass-through link option (`https://biblia.com/bible/...`).
   - **BibleGateway.com:** Pass-through link option (`https://www.biblegateway.com/passage/...`).
   - Configurable default translation (e.g., `ESV`, `NRSV`, `LEB`, `NIV`).
3. **Hover Tooltip Display:**
   - In compiled PDFs viewed in standard PDF readers (Adobe Acrobat Reader, SumatraPDF, PDF-XChange, Foxit), hovering the mouse over a citation pops up a tooltip displaying the verse text.
   - Built using PDF annotation widgets (`pdfcomment`'s `\pdftooltip`).
4. **Offline & Deterministic Verse Architecture:**
   - Compilation MUST NOT depend on live network calls during `lualatex` runs.
   - Powered by a local Lua module (`bibleref-extra.lua`) and an offline JSON/Lua verse cache (`bibleref-verses.json`), with clean fallback if a verse is not yet cached.

## 2. Current Baseline & Architecture (What is Already Proven)

Do NOT modify or break existing proven behaviors:
- **`\bref{s o m}` Router:**
  - Handles starred form `\bref*{...}` (`\pibiblechvs`) and optional argument `\bref[opt]{...}` (`\pibiblevs`).
  - Walks semicolon-delimited lists in reading order.
  - Strips `cf.` prefixes (`cf.\ `, `cf.~`, `cf. `) from the citation engine, typesetting `cf.` as plain text outside the citation.
- **Qumran Shelf Marks:**
  - First token starting with a digit AND containing a capital `Q` (tested via non-recursive bounded scanners `\brx@testfisd` and `\brx@testhasq`).
  - Dispatched to `\qref`, which formats as `\ibibleverse{shelf}(ref)` (or bare `\ibibleverse{shelf}`).
  - Automatically indexed under `28@Qumran` in `<jobname>-ancient-sources.idx` via `imakeidx`.
- **Adjacent Parenthesis Constraint:**
  - `\ibibleverse{shelf}(ref)` requires the opening `(` to be immediately adjacent to `}`. A space between them breaks `bibleref`'s `\new@ifnextchar(`.

## 3. Architecture Design: Hyperlinks & Tooltips

```
                \bref{Gen 1:1; cf.\ 1QS 23:1}
                             │
            ┌────────────────┴────────────────┐
            ▼                                 ▼
   Standard Run: "Gen 1:1"          Prefix: "cf.\ "  Qumran: "1QS 23:1"
            │                                             │
            ├─────────────────────────────────────────────┤
            ▼                                             ▼
  [bibleref-extra.lua]                          [bibleref-extra.lua]
   - Parse Book, Chapter, Verse                  - Parse Shelf Mark & Ref
   - Provider URL (Logos/Biblia/BGW)             - Provider URL (Logos / DSS search)
   - Verse Text Lookup (from JSON cache)         - Verse/Snippet Lookup (if cached)
            │                                             │
            ▼                                             ▼
   \pdftooltip{                                  \pdftooltip{
     \href{URL}{                                   \href{URL}{
       \pibibleverse{Gen 1:1}                        \qref{1QS 23:1}
     }                                             }
   }{"In the beginning..."}                      }{"Community Rule..."}
            │                                             │
            └────────────────┬────────────────────────────┘
                             ▼
           Typeset PDF with SBL formatting + Indexing
           + Plain-Text Clickable Link + Hover Pop-Up
```

### 3.1 Plain-Text Styling
To make hyperlinks appear identical to plain text:
- When `hyperref` is loaded with `hidelinks`, links have no borders and no colored text:
  ```latex
  \usepackage[hidelinks]{hyperref}
  ```
- Additionally, in the macro wrapper, enforce local text color and font inheritance:
  ```latex
  {\hypersetup{hidelinks}\href{<URL>}{<Rendered-Text>}}
  ```
  This ensures that even if a document enables global `colorlinks=true`, scripture citations remain seamless with the running prose.

### 3.2 Provider URL Specifications

The Lua engine `bibleref-extra.lua` will format URLs according to the selected provider:

#### Provider 1: Logos Bible App (Default: `logos`)
Logos uses its official reference redirection service **`ref.ly`**, which deep-links directly into the passage on `app.logos.com` (or opens desktop Logos if configured by user browser):
- **Passage Shortlink:**
  `https://ref.ly/<Book><Chapter>.<Verse>?translation=<Translation>`
  *Examples:*
  - `Gen 1:1` (ESV) $\rightarrow$ `https://ref.ly/Gen1.1?translation=ESV`
  - `John 3:16-17` (NRSV) $\rightarrow$ `https://ref.ly/Jn3.16-17?translation=NRSV`
  - `1 Pet 2:9` (LEB) $\rightarrow$ `https://ref.ly/1Pet2.9?translation=LEB`
- **Qumran Shelf Marks in Logos:**
  - For Dead Sea Scrolls texts, Logos uses resource IDs or general reference search:
    `https://ref.ly/logosres/dssse?ref=<Shelf>.<Ref>` or fallback to:
    `https://app.logos.com/search?q=<Shelf>+<Ref>`
  - *Example:* `1QS 23:1` $\rightarrow$ `https://app.logos.com/search?q=1QS+23:1`

#### Provider 2: Biblia (`biblia`)
Biblia (Faithlife's online web reader):
- **URL Pattern:** `https://biblia.com/bible/<translation>/<Book><Chapter>.<Verse>`
  *Examples:*
  - `Gen 1:1` (ESV) $\rightarrow$ `https://biblia.com/bible/esv/Gen1.1`
  - `John 3:16` (LEB) $\rightarrow$ `https://biblia.com/bible/leb/John3.16`
- **Fallback for Qumran / Non-Biblical:**
  Biblia does not host DSS shelf marks. For Qumran texts, fallback gracefully to Logos search or omit link (plain text only).

#### Provider 3: BibleGateway (`biblegateway`)
- **URL Pattern:** `https://www.biblegateway.com/passage/?search=<Book>+<Chapter>%3A<Verse>&version=<Translation>`
  *Examples:*
  - `Gen 1:1` (ESV) $\rightarrow$ `https://www.biblegateway.com/passage/?search=Genesis+1%3A1&version=ESV`
  - `1 Cor 13:4-7` (NIV) $\rightarrow$ `https://www.biblegateway.com/passage/?search=1+Corinthians+13%3A4-7&version=NIV`
- **Fallback:** BibleGateway does not host Qumran. Fallback to Logos or omit link.

### 3.3 PDF Tooltip Mechanism (`pdfcomment`)

- **Package:** `\usepackage{pdfcomment}`
- **Nesting Rule:** Always place `\href` **inside** `\pdftooltip`:
  ```latex
  \pdftooltip{\href{<URL>}{<Typeset-Citation>}}{<Tooltip-Verse-Text>}
  ```
- **Tooltip Content Sanitization:**
  - The tooltip text must be a single-line or cleanly escaped string without unexpanded LaTeX macros or active TeX formatting.
  - Lua will strip any dangerous characters (`"`, `\`, unescaped braces) and provide a clean UTF-8 string.
  - If a verse is missing from the cache, the tooltip provides a helpful navigation label:
    `[Genesis 1:1 (ESV) — Click to open in Logos]`
    Hovering is always useful and never fails.

## 4. Offline Verse Cache & Architecture

### 4.1 Storage Format: `bibleref-verses.json`
To ensure zero build latency, zero external network dependency, and sandbox compatibility, verse texts are stored in a local JSON file in the document or package directory:

```json
{
  "_meta": {
    "translation": "ESV",
    "updated": "2026-11-25"
  },
  "Gen 1:1": "In the beginning, God created the heavens and the earth.",
  "John 3:16": "For God so loved the world, that he gave his only Son, that whoever believes in him should not perish but have eternal life.",
  "Num 17:12": "And the people of Israel said to Moses, 'Behold, we perish, we are undone, we are all undone.'",
  "1QS 23:1": "[Rule of the Community 23:1]"
}
```

### 4.2 Lua Engine Lookup (`bibleref-extra.lua`)
The Lua engine:
1. Loads `bibleref-verses.json` once into an in-memory Lua table `brx_verse_cache`.
2. Normalizes input keys (e.g. `Gen. 1:1` $\rightarrow$ `Gen 1:1`).
3. If found: returns the verse text.
4. If not found: returns `"<Book> <Chapter>:<Verse> (<Translation>) — Click to open in <Provider>"`.

### 4.3 Helper Utility: `scripts/fetch_verses.py`
Provide a lightweight Python utility to pre-populate or update `bibleref-verses.json` for a `.tex` document:
- Scans `.tex` files for `\bref{...}` and `\qref{...}`.
- Queries a free/open Bible API (or local Bible database) to fetch text for the requested translation.
- Writes entries to `bibleref-verses.json`.
- The local agent can build and test with a starter `bibleref-verses.json` containing the test suite's verses.

## 5. Detailed LaTeX & Lua Implementation Plan

### 5.1 Package Configuration API

In `bibleref-extra.sty`, provide package options and a setup macro:
```latex
\RequirePackage{kvoptions}
\SetupKeyvalOptions{
  family=brx,
  prefix=brx@opt@
}
\DeclareStringOption[logos]{provider}       % logos | biblia | biblegateway
\DeclareStringOption[ESV]{translation}     % ESV, NRSV, LEB, etc.
\DeclareBoolOption[true]{tooltip}          % enable/disable hover tooltip
\DeclareBoolOption[true]{links}            % enable/disable hyperlinks
\DeclareBoolOption[true]{hidelinks}        % style links as plain text
\ProcessKeyvalOptions*

% Runtime configuration macro:
\newcommand{\brxsetup}[1]{\setkeys{brx}{#1}}
```

### 5.2 The Lua Engine: `bibleref-extra.lua`

Create `bibleref-extra.lua` in the package directory. It exposes:
- `brx.init(provider, translation, tooltip_enabled, json_path)`
- `brx.make_url(raw_item, is_qumran)`: Generates the destination URL.
- `brx.get_tooltip(raw_item, is_qumran)`: Returns sanitized verse text or fallback.
- `brx.wrap(raw_item, is_qumran, rendered_content)`: Emits TeX tokens directly:
  - If links and tooltips are enabled:
    `\pdftooltip{\href{<URL>}{<rendered_content>}}{<tooltip>}`
  - If tooltips disabled:
    `\href{<URL>}{<rendered_content>}`
  - If links disabled:
    `<rendered_content>`

### 5.3 Modifying `\bref` and `\qref` in `bibleref-extra.sty`

In the current `bibleref-extra.sty`:
- Standard items were grouped in `\brx@std@run` and flushed together.
- **Key Change for Hyperlinks:** Because each passage (e.g. `Gen 1:1; Num 17:12`) points to a **different URL** and has **different tooltip text**, each passage must be dispatched and wrapped individually!
- Standard items should be dispatched as:
  ```latex
  \newcommand{\brx@dispatch@std@item}[1]{%
    \directlua{brx.wrap_standard([[\unexpanded{#1}]], [[\unexpanded{\brx@dispatch@std{#1}}]])}%
  }
  ```
- Qumran items in `\qref`:
  ```latex
  \newcommand{\qref}[1]{%
    \brx@split{#1}%
    \ifx\brx@ref\@empty
      \def\brx@inner{\ibibleverse{\brx@shelf}}%
    \else
      \def\brx@inner{\ibibleverse{\brx@shelf}(\brx@ref)}%
    \fi
    \directlua{brx.wrap_qumran([[\unexpanded{#1}]], [[\unexpanded{\brx@inner}]])}%
  }
  ```
- Separator `\BRchsep` is inserted between individual wrapped items, preserving reading order and SBL spacing.
- `cf.` prefix continues to print as plain text before the wrapped link.

## 6. Hard Constraints & Known Pitfalls (MUST READ)

1. **No recursive `\ifx` scans:** LuaTeX 1.24.0 has a node-pool bug (`there is a problem in getting a node, case 3`). Keep `\brx@testfisd` and `\brx@testhasq` as bounded scans.
2. **`xstring` bracket syntax:** When using `\StrBefore` or `\StrBehind`, the output container is an **optional bracket argument** `\StrBefore{str}{ }[\res]`, NOT curly braces.
3. **No git commands:** Never execute `git add`, `git commit`, or `git push`. The user handles version control.
4. **`(` adjacency rule:** For `\ibibleverse{shelf}(ref)`, the `(` must touch the closing `}` with no intervening space or macro expansion artifacts.
5. **No network calls during compilation:** Never invoke `curl`, `wget`, or network sockets inside Lua during `lualatex` runs. All verse lookups must be local/in-memory.
6. **Vim swap files:** Check for `.swap/` and do not blindly delete or overwrite files without checking timestamps.

## 9. Acceptance Criteria (Definition of Done)

1. **Visual Styling:** Links in the compiled PDF look like regular text (no colored borders, no blue text unless user changes options).
2. **Correct URLs:**
   - Clicking `Gen 1:1` opens `https://ref.ly/Gen1.1?translation=ESV` (or Biblia / BibleGateway when selected).
   - Qumran shelf marks link to Logos search or designated DSS target without error.
3. **Hover Tooltip:** In supported PDF readers, hovering over `Gen 1:1` shows "In the beginning, God created the heavens and the earth."
4. **Independent Links in Lists:** In `\bref{Gen 1:1; Num 17:12}`, each citation has its own link and tooltip; semicolons and spaces are plain text.
5. **No Regressions:**
   - Starred `\bref*` and bracketed `\bref[opt]` function properly.
   - `cf.` prefixes remain outside the link and print cleanly.
   - SBL formatting and index generation (`imakeidx` ancient sources) remain byte-for-byte intact.
6. **Zero External Network Dependencies at Compile Time:** Compilation succeeds completely offline.
